# Gmail Spam Detector Add-on

This project is a Gmail Add-on that classifies emails as spam or ham using a custom-trained machine learning model based on the Enron email dataset.

## Features

- Gmail integration using Google Apps Script
- ML-powered spam classification via REST API
- Custom model trained on Enron corpus
- Deployable via Flask/FastAPI backend

## 📂 Dataset

This project uses the [Enron Email Spam Dataset](https://github.com/MWiechmann/enron_spam_data), available for research purposes.
